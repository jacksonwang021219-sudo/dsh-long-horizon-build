# DeepSeek Harness

English | [中文](README.zh.md)

> **This checkout is a long-horizon snapshot of DeepSeek Harness** (upstream
> `master` at `47f9438`, MIT) with a sliding-window context policy added: the
> most recent user requests stay verbatim, the traces that answered older ones
> are replaced by records the window writes for itself at fold time, and the
> harness keeps its own `compaction-basic` underneath. The `long-horizon` agent
> preset ships with the deployment and new sessions start on it. See
> [LONG-HORIZON.md](LONG-HORIZON.md) (中文) for how to start the Web UI in this
> mode, the `dsh-context-window` plugin, and the exact delta against upstream.

DeepSeek Harness (`dsh`) is an open-source agent harness developed by [DeepSeek AI](https://deepseek.com).

It uses an architecture where **everything is a plugin**, and is powered by [Cordis](https://github.com/cordiverse/cordis), whose design is described in [_A Programming Paradigm for Spatiotemporal Composability_](https://github.com/cordiverse/paper).

## Developer preview

DeepSeek Harness is currently in _developer preview_ and is iterating rapidly. **THERE WILL BE COMPATIBILITY-BREAKING CHANGES.**

## Run

### Run from `npm`

Install `Node.js`, then run:

```sh
npx @deepseek-ai/dsh web
```

The command starts the Web UI, served at `http://127.0.0.1:3080` by default. See [Web UI guide](docs/user/guide/index.md).

### Run from source

To run from a repository checkout:

```sh
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```
